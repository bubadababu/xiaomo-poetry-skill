# 交付验收清单

## 内容

- [ ] 诗题、作者、朝代、体裁正确
- [ ] 原文完整，四页引用一致
- [ ] 版本来源或版本说明清楚
- [ ] 不确定信息已标记，没有强行编造
- [ ] 拼音准确且对应语境
- [ ] 重点词义真正服务于理解
- [ ] 逐句解释覆盖全部诗句
- [ ] 全诗小结不空泛、不添加诗外事实

## 图片

- [ ] 恰好有 4 张正式 PNG
- [ ] 均为 1920 × 1080 横版
- [ ] 文件名顺序为 01–04
- [ ] 标题、原文和小标题清晰可读
- [ ] 没有乱码、漏字、文字溢出或过小字号
- [ ] 四页风格统一，信息密度符合页面职责
- [ ] 背景没有水印、现代物件或错误文字

## 工程

- [ ] `content.json` 通过 `validate_content.py`
- [ ] `generation.json` 包含版本、时间、四页主题和提示词
- [ ] `verify_output.py` 返回成功
- [ ] 单页可以独立重新生成
- [ ] 输出不包含密钥、隐私信息或敏感绝对路径
