# V0.1 架构

```text
用户输入
  ↓
诗歌识别与版本选择
  ↓
结构化内容 content.json
  ↓ 内容校验
四份 page task
  ↓ 每页独立调用图像生成
四张无文字底图
  ↓ 确定性中文排版
四张正式 PNG + generation.json
  ↓ 产物校验
交付
```

## 设计边界

V0.1 是由 Codex 调度的 Skill，不包含用户系统、数据库、后台和复杂前端。内容推理与内置图像生成由 Agent 完成；脚本负责确定性的格式检查、任务文件构建、中文排版和产物验收。

## 失败策略

- 内容校验失败：停止生图，先修复内容对象。
- 单页底图失败：只重试该页，最多两次；仍失败则明确报告，不伪装完成。
- 排版溢出：优先精简文案或切换紧凑布局；不得使用难读小字。
- 资料不确定：保留警告，必要时要求用户确认版本。
- 缺少 AI 底图：允许生成 `preview` 预览图用于本地测试，但不能在交付记录中冒充 AI 正式底图。

## 可扩展点

`content.json` 可以直接成为网页、PDF、课件或批量任务的输入。V0.2 以后可以增加教材版本库、人工复核界面、批量队列和多套视觉模板，不需要改变四页的教学逻辑。
